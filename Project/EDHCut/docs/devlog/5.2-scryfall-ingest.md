# Task 5.2 — Scryfall ingest + name resolution table
Date: 2026-07-29 | Status: done

Populated `cards` (**31,622** commander-legal cards) and `card_names` (**33,220** aliases)
from the Scryfall `oracle_cards` bulk file.

## Decisions
- Row-oriented dicts straight into `executemany`, not pandas — the target is the SQL column
  shape, not an analysis-ready DataFrame.
- `oracle_text`/`mana_cost` fall back to `" // "`-joined `card_faces` values, so DFC / split /
  adventure cards still carry text for downstream mining.
- `can_be_commander` = Legendary Creature **or** "can be your commander" anywhere in the
  resolved oracle text — catches Backgrounds and commander planeswalkers with no hardcoded list.
- One `normalize_name()` applied uniformly to every alias (explicit æ→ae / œ→oe, then NFKD +
  drop combining marks, then collapse non-alphanumerics).
- Idempotency by upsert, not delete-and-reinsert: later tables hold foreign keys into `cards`
  and `PRAGMA foreign_keys = ON` would reject the deletes. Accepted gap — a card that loses
  commander legality stays in the table with stale data.

## Bugs
- **The `games` filter silently dropped 1,048 legal cards.** The original filter required
  `"paper" in games` alongside `legalities.commander == "legal"`. `games` describes the single
  *representative printing* Scryfall picks per `oracle_id`; for cards later reprinted
  MTGO-only (the Masters Editions, Vintage Masters) that printing is digital, so Tundra, Wheel
  of Fortune, Strip Mine and 1,045 others were excluded. Surfaced when task 5.3-B started
  flagging obviously legal cards as illegal. `legalities.commander` alone is correct and
  sufficient (Alchemy-only cards report `not_legal` on their own); `is_paper()` was deleted.
  Re-ran: 30,574 → 31,622 cards, and decks harvested against the old table were cleared.
- Scryfall's bulk-data API changed since the plan's investigation: `download_uri` →
  `jsonl_download_uri`, gzip JSONL instead of one JSON array (23.2 MB, not the plan's 179.8 MB).
  Parsed line-by-line via `iter_bulk_cards()`, which task 5.5 reuses.

## Outcome
Done, with a regression test pinning the legality filter to `legalities.commander` alone.
Lesson worth keeping: single-printing fields (`games`, `set`, `collector_number`) are unsafe
proxies for card-level facts; computed fields like `legalities.*` are fine.
