# Task 6.3 — Synergy communities
Date: 2026-08-09 – 2026-08-12 | **Status: superseded 2026-08-13**

> **⚠ Read [6.3d-soft-communities-and-edge-quality.md](6.3d-soft-communities-and-edge-quality.md)
> for the current pipeline.** Soft clustering via NMF (below) was dropped at the user's direction:
> the communities were too large, the colour-bias problem it existed to solve was never solved,
> and the tooling wasn't understandable enough to reason about. What survives from this document
> is the confound diagnosis, the corpus rebuild, and the graph-construction rules.

Detect card packages ("goblin payoffs", "sac outlets") via community detection over 6.1's
association data. Success criterion, set before looking: clusters should read as real archetypes
without a human squinting.

## Decisions
- **Global scope only, not per-slot** — `cluster_of()` must generalize to commanders outside the
  roster, and per-slot t-score matrices are 64–96% zero-degree rows anyway.
- **t-score, not PMI** (the decision 6.1b deferred): PMI ties rare coincidental pairs at a
  ceiling, exactly the noise that would show up as spurious tight clusters.
- **Graph**: each card's top-15 positive edges, **union**-symmetrized, not mutual — so a rare
  synergy piece whose #1 partner is a generic staple isn't dropped when the staple doesn't
  reciprocate.
- **Only the 5 basic land types excluded**, decided from measured degree (basics 1,000+ against a
  median of 15) rather than a blanket "exclude lands" rule. Basics are mechanically distinct:
  zero oracle text, fungible within a color.
- **Near-uniform deck weighting for community detection** (`compute_near_uniform_weights`,
  `median(n_s)/n_s`), *not* `compute_deck_weights`'s true-share formula — that one restores a
  commander's real metagame share, which is what play-rate wants and what communities must not
  have. Nearly wired up wrong; caught by re-reading the module docstring.

## Bugs
- **The clusters were the five commanders, not card packages.** Modularity looked healthy
  (0.66–0.67) while the output didn't — 6–11 clusters, the biggest holding 1,600+ of 4,767 cards.
  Measuring cluster/slot purity directly showed each cluster was one commander's deck pool
  (66.9–98.8% pure). Cause: t-score's null draws marginals from five pooled commanders, so any two
  same-slot cards score high for co-slot membership alone. Goblin Warchief + Skirk Prospector
  drops from t=20.6 to 0.98 under stratification, while Sol Ring + Arcane Signet barely moves —
  the control confirming the diagnosis. **Fixed at the source by task 5.7's corpus broadening**;
  stratification was prototyped but rejected (it degenerates as strata shrink toward 1).
  Same lesson as 6.1's PMI ties: a healthy aggregate metric doesn't substitute for looking at the
  output.
- **A residual confound survived the rebuild**: 3 clusters were still 42–59% Krenko/Kyler/Yenna,
  because broadening the corpus doesn't shrink those commanders' own oversampled deck counts.
  Fixed by near-uniform weighting (that pair's t-score dropped 35.2 → 6.2). Note that purity must
  be re-measured *under the same weighting the graph used* — the raw lens stops being fair once
  one commander has ~200x a typical slot's decks.
- **The 5.7 dense-matrix guardrail fired as a false positive** at 18,979 cards (2.68 GiB by the
  `n²` estimate). Real allocation is ~63 MiB — nothing does a full-pool dense conversion. Removed
  the blanket calls, kept the one genuine call site.
- **NMF needed *every* land excluded, not just basics** — with basics-only, topics read as
  color-pair mana bases and Cultivate smeared across 5 of them. A nonbasic land is present in most
  decks sharing its color pair, an easy dense block for Frobenius-loss NMF to spend components on.
  Pairwise t-score never hit this, which is why basics-only sufficed there.

## Outcome
Superseded, but the rebuild's qualitative check did pass at the time: Skirk Prospector's cluster
read as Rakdos goblins, Cultivate's as Naya ramp. NMF added soft membership (86.2% of cards in
2–5 topics), with slot oversampling handled by subsampling to 25 decks/slot rather than weighting
(sklearn's NMF has no sample weights, and scaling a binary presence row corrupts its semantics).

Two problems drove the eventual reset, both recorded here first:
- **Granularity**: 40 topics against EDHREC's ~400-tag taxonomy. Root cause is corpus depth, not
  the algorithm — Leiden's resolution sweep and NMF's k-sweep independently topped out far short,
  and NMF cost scales ~k^2.25, so a stability-checked sweep to k=500 would be a week of compute.
- **Same-color legality bias**: fixed for t-score in 6.1's addendum, but NMF has no null model to
  correct, so it doesn't transfer — several topics sit at 80–93% single-color purity.
