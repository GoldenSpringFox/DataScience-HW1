# Task 6.2 — Card embeddings + similarity index
Date: 2026-08-07/08 | Status: done

Two vector spaces per card: **Word2Vec** over decklists ("travels together in practice",
7,537 cards in vocabulary) and **TF-IDF+SVD** over rules text ("does a similar thing", all
31,623 commander-legal cards — including ones too rare for Word2Vec to place). Both
independently reproduce the plan's success criterion: Cultivate → **Kodama's Reach** at #1.

## Decisions
- **Word2Vec**: skip-gram, 64 dims, `window=100`, `min_count=3`. Deck card order out of the DB
  is arbitrary, so `ShuffledDeckCorpus` reshuffles each deck per epoch — needed even with a
  window larger than any deck, because gensim's *dynamic* window means one pass doesn't see
  every in-deck pair.
- **The `tfidf` space is four independently L2-normalized blocks at fixed weights** — oracle
  text 0.5, type line 0.1, mana cost 0.3, power/toughness 0.1 (weights supplied by the user and
  revised twice against named live examples). Oracle text and type line get *separate* TF-IDF
  spaces: sharing one bag-of-words meant that for terse vanilla cards the type word "Human"
  outweighed the actual mana ability, burying Llanowar Elves at rank 496 for Avacyn's Pilgrim.
- **Structured features are concatenated onto `tfidf` only, never Word2Vec** — rules text
  carries no cost/color signal, which is exactly the gap Word2Vec doesn't have (it encodes color
  identity implicitly through which decks a card can appear in). Boolean flags stay literal 0/1,
  not z-scored, so "is this even a creature" remains readable.
- **No stopword filtering on oracle text.** A hand-curated "words that matter in Magic" list can
  never be complete, and TF-IDF's IDF term already down-weights ubiquitous words — that's the
  mechanism stopword lists approximate by hand.
- **Reverted the cost/effect-tagging + bigram analyzer** after user pushback: TF-IDF is
  bag-of-words, and building preprocessing to fake word order is fighting the method rather than
  accepting it. Honest cost of the reversion — cards whose text merely *contains* `{w}`/`{t}`
  moved from rank 422/932 back to 52/94, though still outside any practical top-15.
- **Land/nonland is a substitution boundary no statistical method knows about**, so
  `card_categories.same_category_mask()` was built once and applied to *both* 6.1 and 6.2
  (`include_cross_category=False` by default). A deck's land count is near-fixed regardless of
  its nonland cards, so a land's relationship to any one card reflects mana-base requirements,
  not substitutability. Before the filter, 14 of Avacyn's Pilgrim's top 15 were lands.

## Bugs
- **CMC couldn't express distance at all — a representation bug, not a weighting one.** A single
  z-scored `struct_cmc` folded into a cosine block is scale-invariant along its own axis, so
  CMC 2 and CMC 5 score *perfectly* similar. No reweighting of a scalar can fix that. Replaced
  with `_cmc_bucket_vector`, a Gaussian bump across integer CMC buckets, so similarity decays
  monotonically with distance (CMC 1 vs 6 → 0.0019).
- **The `struct_*` block silently dominated the cosine search**: its average row norm was ~4x
  the TF-IDF block's despite far fewer dimensions, so neighbors were *only* same-cost same-color
  cards. Fixed by per-block L2 normalization before concatenation (which the final fixed-weight
  design supersedes).
- **DFC power/toughness were mis-flagged as variable.** Stats are stored `"1 // 4"`-shaped;
  `float(raw)` fails, then the `*`-stat regex matched the leading `"1"` — right number, wrong
  flag. Now detects `" // "` first and parses the front face directly.
- **gensim has no Python 3.14 wheel and won't build from source there** (its pre-generated C
  calls CPython internals 3.14 changed — confirmed with a full MSVC toolchain install, not a
  missing-compiler issue). Resolved with a second `venv311/`; gensim/scikit-learn moved to an
  `embeddings` extra and imported lazily, so the main venv still installs cleanly and only the 3
  Word2Vec tests are gated. This reintroduces the dual-venv setup 5.1 deliberately reverted —
  but that was avoidable duplication, this is a genuine incompatibility with no workaround.

## Outcome
Done. Both spaces validated live on named cards throughout: Avacyn's Pilgrim's final `tfidf`
top-15 is essentially every classic 1-mana dork across all colors, with Cultivate → Kodama's
Reach held as a regression guard through every revision.

`notebooks/embeddings_exploration.ipynb` carries interactive t-SNE maps for both spaces —
click a point to get the card image, its top-5 neighbors on the map, and its true top-5
neighbors in the full space. Ranked by `playrate.py` rather than raw deck count (see
[play-rate-metric.md](play-rate-metric.md)), since Word2Vec occurrence counts triple through
the shuffled corpus.
