# Task 6.3-C — Louvain communities + interactive graph
Date: 2026-08-13 | Status: superseded in part by 6.3-D

> **⚠ Read [6.3d-soft-communities-and-edge-quality.md](6.3d-soft-communities-and-edge-quality.md)
> for the current pipeline.** Every open problem listed here was addressed there, and symNMF is
> now the default clustering; this notebook remains as the hard-partition comparison. All counts
> below describe a pre-gate build; the findings and reasoning still hold.

User-directed reset away from 6.3-B's soft clustering: back to Louvain — taught in the user's
course, hard partition, recursive levels, visible modularity — plus one interactive 2D graph.
Hypothesis was that the simpler method wouldn't do worse. It did substantially better.

## Decisions
- **networkx over igraph**: `louvain_partitions` yields *every* level of the recursive merge from
  one run, which is the granularity ladder for free. 3.5s on the 18k graph, so performance wasn't
  a factor.
- **ipysigma over pyvis/plotly**: takes a networkx graph directly and runs ForceAtlas2 in the
  browser on WebGL, so edge weight becomes attraction — exactly the "strong clusters sit near each
  other" requirement, with no precomputed layout. pyvis tops out around 1–2k nodes against 18k.
- **γ=2.0 and level 0**, not γ=1 or the final level. Sweeping the *final* partition across γ ∈
  [0.5, 5] never exceeded 24 package-sized communities; level 0 of a single γ=2 run gives 114.
  The level hierarchy is the granularity knob; γ is secondary.
- **Colour bias measured, then accepted.** Louvain on plain vs colour-conditioned matrices gives
  the same purity (52.9% vs 52.1%, null ≈20%) — a third method agreeing the colour signal is in
  the data, not the algorithm. Decided with the user to stop trying to remove it and report it
  per community instead. The colour-conditioned matrix is still used, on a different
  justification: it splits better.
- **Communities are named automatically from `card_tags`**, scored `share × log(1+lift)` — chosen
  over TF-IDF on type line because Tagger already encodes mechanics rather than surface features.
  `share` alone picks vacuous tags every card carries; `lift` alone picks freak tags on 4 cards.

## Bugs
- **The near-uniform weighting silently regressed.** The notebook loaded the saved
  `tscore_color_global.npz` — and every saved matrix under `data/kb/dev/` is *unweighted*, because
  `cooccurrence.build_and_save` never passes `deck_slot_weights` and has no parameter to.
  `communities.build_and_save` works around this by rebuilding its own; the notebook didn't.
  **Caught by the user from the picture** — visible Krenko and Kyler blobs — before any metric
  flagged it. Correcting it cut the Krenko-dominated community from 1,026 cards to 487. Modularity
  fell 0.699 → 0.576, which is the expected cost, not a loss: the oversampled blocks were dense
  and trivially separable, so they were inflating Q. A permanent guard section now exists.
- **The first domination metric was vacuous.** "Card appears in ≥1 Krenko deck" qualifies 2,900
  cards at 2,007 decks and reported 95% domination for every build including good ones. The
  measure that works is a card in **≥50% of that slot's decks** (Krenko: 29 cards).
- **`deck_cards` has no index on `oracle_id`**, so a per-neighbour query meant ~31 full scans of
  1.06M rows and `neighbors()` took minutes. Rewritten as a single self-join: 0.10s. The index
  itself is still not added.

## Outcome
Done, and the qualitative check passes: level-0 communities read as real packages — Extra Turns,
Shrines, Cascade, Allies, Necrons, Deserts, Equipment, Landfall. The 40 NMF topics never did this.

The naming system's **failures are the diagnostic**: a community whose best tag has lift < 3 gets
`(generic — no distinctive tag)`, and that fires on exactly the staple piles (5 of the 12 largest,
29 of 214) — an automatic detector for low-quality communities.

Three open quality problems, all handled in 6.3-D:
1. **t-score is a significance measure, not an effect size.** Lion Sash's 18 strongest edges span
   t-scores of 2.98–4.41 while lift spans 1.2–62; Arcane Signet ranks 9th by t-score and last by
   lift. `(obs−exp)/√obs` means a tiny *relative* excess on a large count is many sigma, so
   generic staples tie with genuine synergy pieces.
2. **The low-degree tail pollutes communities** — cards with one weak edge get filed wherever it
   points. Not always wrong, but mostly.
3. **Precon shells survive `precon_card_weight`** — one 18-card community is 16 cards from a
   single Marvel precon, and because Louvain is a hard partition, a reprinted staple caught in it
   (Lethal Scheme) exists nowhere else.
