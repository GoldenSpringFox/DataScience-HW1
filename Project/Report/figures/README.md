# Report figure generation

Every figure and card panel in `../report.md` is generated by a script here, from the live
knowledge base in `Project/EDHCut/data/`. Nothing is hand-drawn, so any figure can be rebuilt.

Paths are resolved from each script's own location, so they run from anywhere. You need the data
directory (repo README §4) and the main venv:

```bash
venv/Scripts/python "Project/Report/figures/figs2.py"
```

## Building the PDFs

```bash
venv/Scripts/python "Project/Report/figures/build_pdf.py"
```

Writes `../writeup.pdf` (everything) and `../noimages.pdf` (the same document with every figure
**and its caption** removed, which is what the 6-page limit is measured against), plus
`../report_noimages.md`. Needs LibreOffice at the path in `SOFFICE` and the `markdown` package.

It also strips HTML comments and any unfilled `[Friends - ...]` / `[Cards - ...]` placeholder lines
left in `report.md`.
