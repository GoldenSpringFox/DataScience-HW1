# Report figure generation

Every figure and card panel in `../report.md` is generated by these scripts, from the live
`Project/EDHCut/data/` knowledge base. Nothing here is hand-drawn, so any figure can be rebuilt.

**Run everything from `Project/EDHCut/`** (the scripts resolve `data/kb/dev/...` relative to the
working directory), using the repo's main venv:

```bash
venv/Scripts/python "Project/Report/figures/figs2.py"
```

## What builds what

| script | figures |
|---|---|
| `figs2.py` | Fig 1 card popularity, Fig 4 lift fails, Fig 5 t-score fails, Fig 6 the product, Fig 7 Jaccard gate, Fig 8 staple detector |
| `cards2.py` | Fig 2 Thornbite Staff metric comparison, and the pair panels behind Figs 4-5 |
| `cards.py` | shared card-image helpers (`card`, `grid`) - not run directly |
| `kb.py` | shared loader: card index, t-score, lift, the 12 format staples, sparsification - not run directly |
| `ch2_build.py` | **run first for any Question 2 figure.** Rebuilds the symNMF communities and caches `ch2.pkl` |
| `ch2_figs.py` | Fig 9 community graph, Fig 13 packages by rank, Fig 14 color purity |
| `ch2_cards.py` | Fig 10 dragon packages, Fig 11 Mondrak's packages |
| `ch2_mondrak_graph.py` | Fig 12 Mondrak's connections |
| `ch3_figs.py` | Fig 18 lift within each group |
| `ch3_cards.py` | Fig 16 Skullclamp's two neighbour lists |
| `ch3_tsne.py` | Fig 17 the text space |
| `ch3_wordcloud.py` | Fig 19 oracle-text word cloud |
| `seed_stability.py` | the seed-stability numbers quoted in Question 2 (writes `seed_stability.json`) |
| `fig_color.py` | the color-correction chart - **not currently used in the report**, kept because the numbers are quoted in Question 1 |
| `build_pdf.py` | both submission PDFs (see below) |

`ch2.pkl` is not committed; run `ch2_build.py` to regenerate it (~30s).

## Building the PDFs

```bash
venv/Scripts/python "Project/Report/figures/build_pdf.py"
```

Writes `../writeup.pdf` (everything) and `../noimages.pdf` (same document with every figure **and its
caption** removed, which is what the 6-page limit is measured against). It also writes
`../report_noimages.md`. Needs LibreOffice at the path in `SOFFICE`, and the `markdown` package.

Two things the build strips from both PDFs: HTML comments, and any unfilled `[Friends - ...]` /
`[Cards - ...]` placeholder lines still sitting in `report.md`.
